# Sources and licences

Two real Ogg Vorbis recordings from the NASA archives, downloaded from Wikimedia
Commons. Ogg is not text and not one of the image types the browser displays
natively, so this pair reaches the blob terminal: the reviewer sees the two
media types, sizes, and digests, and no error `LazyFile`.

Audio was chosen because a replaced sound asset is an ordinary thing to find in
a repository, and because nothing about the bytes tempts either side of the
system into guessing at structure it does not have.

### `old.ogg` — the sound clip the repository shipped before

- Source: https://commons.wikimedia.org/wiki/File:Apollo_8_go_for_TLI.ogg
- File: https://upload.wikimedia.org/wikipedia/commons/f/fb/Apollo_8_go_for_TLI.ogg
- Licence: Public domain
- Author: NASA
- Retrieved: 68892 bytes, application/ogg
